# Quantitative Trading With Machine Learning

## Setup and Run Instructions

This project was developed and executed using **Google Colab**. No local Python or VS Code setup is required.

### 1. Open the Project

Open the provided Google Colab notebook from the GitHub repository.

### 2. Open in Google Colab

Upload or open the notebook (`.ipynb`) in Google Colab.

### 3. Dataset

Upload the required dataset files to the Colab environment or place them in the specified project/data location used by the notebook.

### 4. Run the Notebook

Run the notebook cells sequentially from the beginning.

The notebook performs the following:

* Loads the dataset
* Preprocesses the data
* Performs feature engineering
* Trains the machine learning models
* Generates predictions
* Generates trading signals
* Performs backtesting
* Calculates portfolio performance metrics
* Generates the required results and visualizations

### 5. Results

After executing all cells, the generated predictions, trading results, portfolio analysis, and visualizations can be viewed in the notebook and/or the generated output files.

### Requirements

The project was executed in Google Colab. Required Python libraries are installed within the Colab environment as needed by the notebook.
